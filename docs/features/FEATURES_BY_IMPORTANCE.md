# TableTab feature catalogue by importance

Generated from the app's feature list (features.js). Every feature has a level (1 = the product needs it, 4 = premium extra), an area, and the bundle it sits in today.
The super console lets you move any feature between bundles and lock it per café, so nothing here is final.

## Features by importance

### Level 1 - Core
The product does not work without these. Give them to everyone.

| Feature | Area | What it does | Why a café pays | Running cost to you | Starter | Operations | VIP |
|---|---|---|---|---|---|---|---|
| **Digital menu** | Guest side | A bilingual digital menu with photos, categories, search and a dish of the day. | Replaces printed menus. The reason a café signs up at all. | None | yes | yes | yes | yes |
| **Table QR codes** | Guest side | One QR code per table that opens the menu for that exact table. | Guests need no app. Printable QR sheets. | None | yes | yes | yes | yes |
| **Owner dashboard** | Owner dashboard | Owner dashboard: edit menu, prices, tables, theme, reports. | The owner runs the café without calling you. | None | yes | yes | yes | yes |
| **Call waiter / requests** | Guest side | Guests tap to call the waiter, ask for water, the bill, etc. | Faster service with fewer staff. | None | yes | yes | yes | yes |
| **Captain takes orders at the table** | Staff side | The captain taps the guests order into the captain screen and sends it, so the guest does not need to order from the phone. | Lets a cafe start cheap: QR menu and calling, with the captain doing the ordering. | None | yes | yes | yes | yes |
| **Ordering from the table** | Guest side | Guests order from their phone, staff see it on the captain screen. | Fewer mistakes, faster turnover, bigger orders. | None | - | yes | yes | yes |
| **Item options (size, extras, milk, sugar)** | Guest side | Size, milk, sugar and extras with price changes, required or optional choices. | Cafés cannot sell coffee properly without it. Raises average ticket. | None | - | yes | yes | yes |

## Deciding prices - questions to ask

1. Which Level 1 and 2 features would a small café refuse to live without? Those define the entry bundle.
2. Which features cost you money to run (AI, Paymob support, ETA)? Keep them out of the cheapest bundle.
3. Which features raise a café's revenue (options, upsell, online ordering, reservations)? Those justify the middle bundle's price.
4. Which features only bigger venues need (branches, recipes, loyalty, gift cards, AI)? Those justify the top bundle.
