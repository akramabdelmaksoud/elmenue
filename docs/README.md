# Documentation

- `guides/` - how to run, launch and operate TableTab (go live, production, pilot checklist, owner checklist)
- `features/` - the feature catalogue by importance level (generated by `node scripts/gen-features.js`)
- `business/` - plans, pricing report and brand exploration
- `archive/` - old release audits and prompts kept for reference
- `tools/` - helper scripts
